### 投稿與公開

- 訪客免登入，填寫署名，搭配防濫用措施；措施尚待設計。
- 電話與 Email 均選填，均不公開。未填者可能無法後續聯絡。
- 雲端可靠收件後立即公開文字；其他訪客重新整理可看見。無須先審核；是否推送自動更新尚未決定。
- 接受照片、影片直接上傳及 YouTube 連結，鼓勵以 YouTube 連結降低上傳量。其他外部影片平台及自動上傳至 YouTube 未核定。
- 無附件當純文字處理。附件未完成處理可顯示狀態；大型檔案無法上傳時允許失敗，再由管理員聯絡，不要求斷線續傳。
- 使用者未設定容量上限，希望先盡量承接；不能解讀為無限容量或已保證任何檔案均可上傳。實際大小、格式、服務限制及失敗後文字公開細節需於實作時明訂。
- 保留每則最多 10 個附件及其他既有網站維護規範。

### 歸檔與資料

- Supabase 為主要後端方向；Drive 為素材歸檔目的地。影片處理、收件及背景歸檔分開，Drive 歸檔不作為收件成功的同步必要條件。
- 投稿資料、附件及歸檔檔案需可相互對應，方便整理與後續應用；歸檔需有狀態、失敗重試及防重複設計。
- 投稿及附件均採軟刪除：下架後訪客不得讀取本站託管的內容與附件；管理員可查看、恢復，並保留操作紀錄。Drive 原始歸檔保留。
- YouTube 外部影片只能從本站移除，不能保證刪除頻道持有人的原影片。
- 既有 IndexedDB 內容不得默默上傳。

### 管理後台

- 使用簡易帳密登入，依角色授權；未開放訪客註冊。帳號建立及密碼復原流程尚待實作。
- 提供投稿編號、署名、文字、日期搜尋；附件失敗、歸檔失敗、已下架篩選；文字與年代編輯、移除個別附件、整則下架及恢復、修改紀錄、原始附件下載及資料匯出。
- 使用者已同意下列角色配置，實際人員及帳號數量待指定：

| 角色 | 權限 |
| --- | --- |
| 系統管理員 | 全部功能，管理帳號、角色及系統設定 |
| 內容管理員 | 搜尋、編輯、下架、恢復、下載附件；不得查看聯絡資料 |
| 資料整理員 | 搜尋、下載、匯出投稿及選填聯絡資料；不管理帳號或修改內容 |
