# 大呂的音樂，未完待續 v1.1

本版以最初提供的桌面 HTML 為版型，保留原始 CSS、中央標題、流動照片牆、導覽、關於大呂、回憶卡、邀請區、音樂會預覽、時間軸、作品資料庫、音樂會詳情與表單風格。投稿介面簡化為稱呼、文字、附件三項；年代、地點與關係可展開選填。換入真實資料並增加媒體播放、來源註記及已實作的本機保存。

## 開啟與上架

- 直接開啟 `index.html` 即可瀏覽。照片已嵌入，不必另外搬移圖片。
- 放到 GitHub Pages：將 `index.html` 與 `.nojekyll` 放在 repository 最外層；Settings → Pages → Deploy from a branch → main → /(root) → Save。
- 首頁與所有公開資料已能供其他人瀏覽。YouTube 影片在 HTTP/HTTPS 網站內嵌播放；直接雙擊本機 HTML 時會提供原影片連結，避免 YouTube 的來源驗證問題。教育部藝秀臺影片使用官方觀看入口。
- 字型、YouTube 與外部來源需網路連線。Google 字型失敗時仍使用本機中文字型。

## 這一版的內容

- 生涯與演出合併於音樂足跡，預設從 1977 出生開始。21 個生涯節點，從臺東啟蒙、東吳、德國科隆，到合奏教育、跨界與各地演出。
- 42 筆演出／活動紀錄，涵蓋 1999–2025。FGO 的 2019/12/29–30 合併為一筆活動，故數字表示紀錄筆數。
- 220 筆曲目資料（含原定節目）、170 筆目前辨識的作品索引；依原公告記載整理，不是全部演出總數。
- 23 則影像紀錄：15 則照片／節目影像、7 支 YouTube 影片、1 筆教育部藝秀臺影片。
- 另有 2 則親友思念，依使用者提供的 Facebook 截圖摘錄；署名待核對，暫以關係稱呼。Facebook 留言要求登入，未大量匯入或虛構其他留言。
- 投稿支援文字、照片、影片及任意組合；可分次加入附件、移除單一附件，一則最多 10 個。稱呼留白則匿名。
- 影像與文字均有來源。樂團宣傳照、資料照、演出照片與主視覺有各自標示；未冒充親友投稿。

- 回憶文字超過 100 字時收合，顯示「閱讀剩下 X 字」；可展開及收回。以使用者看見的字元計數（含標點、空白與換行；組合 emoji 視為一字）。圖片／影片搭配文字同樣適用。
- 來源連結採小字、65% 不透明度，滑鼠或鍵盤聚焦時清楚顯示。
- 背景音樂只使用 `n7mhsJLAsVk`（Simple Gift: Here Take This Lovely Flower），按播放才載入，單曲循環。播放器可暫停或關閉；打開演出影片時會停止背景音樂。直接雙擊 HTML 則提供同一首的 YouTube 連結；上架 HTTP/HTTPS 後在頁內播放。
- 取消、行前計畫、實際日期待核及指揮身分待核紀錄另有標記，未計入作品演出索引。

## 人工校對

`大呂的音樂，未完待續 v1.1－生涯與音樂歷史校對.txt` 是逐項校對用文字檔，含團體、地點、曲目、署名、完整來源網址與修正欄。

`資料校對.csv` 可用 Excel 開啟，列出每筆生涯、演出、曲目與影片的原始來源及備註。`素材來源.csv` 記錄圖片來源與素材檔名。`校訂注意事項.txt` 整理原始來源之間的年份、署名與日期差異。

若要修改網站，請工程端編輯 `工程檔/content.json`，再於該資料夾執行 `node build.mjs`。新的網頁會輸出至 `工程檔/dist/index.html` 及同名加版號 HTML。執行 `node proofread-v11.mjs` 可重新產出校對文字檔。把它替換成上架用的 `index.html` 即可。CSV 是校對用輸出，修改 CSV 不會自動改到網頁。

`工程檔/template-original.html` 是最初的原版；`additions.css` 只補充影音、來源與功能樣式；`archive.js` 處理真實資料的畫面。建置只需 Node.js，無需安裝套件。

## 收件功能狀態

新增回憶、照片、影片、音樂會、曲目補充與回報草稿會保存至本機 IndexedDB；重整後仍可保留。搜尋、年代排序、相簿翻頁、喜歡、作品跨場次索引可操作。

尚未接共用資料庫、雲端檔案儲存與管理者收件後台。其他訪客看得到內建公開紀錄，但看不到某位訪客在自己的瀏覽器新增的投稿。表單已明示這點。公開收集親友投稿前，工程端須完成這一層串接。
